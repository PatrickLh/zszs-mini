# 修行筹算预览版

运行 `npm run dev`，打开 http://127.0.0.1:5173 。无第三方运行依赖。

- `index.html` / `app.js` / `style.css`：可直接查看的 H5 交互原型。
- `core/planner.js`：独立计算引擎；`npm test` 验证关键材料及解锁逻辑。
- `uni-app/`：同一引擎的 Vue 3 uni-app 页面源文件，可用 HBuilderX 导入；目前未完成小程序编译和真机验证，微信 AppID 留空。
- `uni-app/core/planner.js` 为原型引擎副本，修改引擎后须同步。

当前限制：已有任务进度视为此前奖励已领取；宝库从零兑换进度开始规划，尚未支持本期已有兑换记录。补充获取按全部到账计算，不进行逐日排程。普通/稀有木人直接掉落均排除。

预计用量使用独立木人击败所需攻击次数的数学期望，再逐档计算材料流转，不代表达成概率。保守模式采用每次10伤害。缺口以到达奖励前的最大材料短缺计算，不能使用尚未领取的返还。
